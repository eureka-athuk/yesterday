# База знаний — <дело>

Знание о том, как всё устроено: системы, связи, договорённости, грабли. Здесь лежит разобранное и
проверенное — чтобы не разбирать одно и то же дважды.

## Формат страницы

```markdown
# <Название>

статус: сверено | черновик
дата сверки: YYYY-MM-DD        # для «сверено»
дата записи: YYYY-MM-DD        # для «черновика»
источник: <путь:строка | ссылка | человек (не проверено)>
решение: <дата, автор, формулировка>   # необязательно

## Что это
## Связи
## Что важно знать
## Как проверить / починить
```

## Законы

1. Работающая система главнее страницы. Разошлись — врёт страница.
2. Страница — «что есть сейчас», не летопись. История — в `CHANGELOG` и git.
3. Измеримое не храню — измеряю: где смотреть, а не значение. Исключение — число, ставшее
   решением.
4. Догадка входит только после сверки, с пометкой.
5. Ревизия — `knowledge-review`: старая дата сверки → обновить, править, сократить или удалить.

## Разделы

- <раздел под дело> — <что там>

Разделы — по делу человека, а не «в среднем». Пустая папка «на будущее» не нужна: раздел
появляется с первой страницей и строкой здесь.
