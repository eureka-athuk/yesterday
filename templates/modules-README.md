# Модули

Надстройка для **многопрофильного** ассистента: темы, которые грузятся по требованию. Модуль — папка
со своим `AGENTS.md`; в контекст он попадает только когда тема названа.

Ассистенту одного дела модули не нужны. Они появляются, когда тем несколько и слова из одной мешают
в другой, а в законе уже тесно от подробностей, нужных раз в месяц.

## Как завести модуль

1. Папка `modules/<тема>/`, в ней `AGENTS.md`.
2. `AGENTS.md` — рамка темы: зачем модуль, что в нём есть, куда идти за глубиной. **Знание живёт в
   `knowledge/`**, модуль — вход, а не содержимое.
3. Дописать модуль в карту модулей в корневом `AGENTS.md`. Без этого он мёртвый: сам не загрузится.

## Правила

- Модуль не дублирует базу знаний: тема (общая область) — модуль, факт (как устроен конкретный
  сервис) — страница `knowledge/`.
- Не заводить модуль заранее, под будущее. Появилась тема — тогда и папка.
- Модуль читается, когда тема названа, а не на каждом пробуждении.
