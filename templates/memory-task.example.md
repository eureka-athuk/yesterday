# <ID> — <тема>

Файл одной задачи: долгого дела, тикета, инцидента — если разговор о нём переживает сессию. Имя —
ID (номер тикета) или короткое имя темы латиницей через дефис. Лежит **вне git**, у каждого свои;
строка-указатель — в `memory/local.md`. Является частью слоя состояния: обзор — `local.md`, деталь —
здесь.

Заводить, только когда есть что унести в другую сессию: живой артефакт, незакрытый вопрос,
ожидание чужого ответа, решение человека. Короткому разговору файл не нужен.

## Состояние

Переписывается с нуля при каждом изменении; пустые поля не пишу.

- **Где:** <проект, ветка, окружение — что нужно, чтобы вернуться в задачу>
- **Статус:** <наша работа, а не статус карточки>
- **Сделано и решено:** <что сделано; слова человека помечаю, своё мнение отделяю от его решения>
- **Передано:** <что ушло автору, коллеге, во внешнюю систему>
- **Открыто:** <что ждёт ответа или действия>
- **Как вернуться:** <если это неочевидно из ID>

## Журнал

Только дописывается; задним числом не правится. Идут сюда **только события, которых нет больше
нигде**: решение человека, передача, смена статуса. Пересказ `CHANGELOG/` и `knowledge/` — нет.
Числа, хеши, статусы — это срез на дату записи, а не хранимое знание: вернувшись, сверяю заново.

- <YYYY-MM-DD> — <событие>
